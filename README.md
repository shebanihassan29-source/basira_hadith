# بصيرة الحديث — Basira Hadith

منصة أكاديمية متخصصة في البحث الحديثي، وإدارة البيانات الحديثية، والتخريج، ومقارنة أحكام العلماء، مع توظيف الذكاء الاصطناعي في الاسترجاع والتحليل الموجّه بالمصادر.

## الملكية
© فكرة وتصميم: د. حسن الشيباني

## الإصدار
v0.4 — GitHub-ready prototype

## المنهجية العلمية
- لا يصدر النظام حكمًا حديثيًا من تلقاء نفسه.
- تُحفظ أحكام كل عالم مستقلة مع مصدرها وموضعها.
- يُميّز بين الحكم على الإسناد والحكم على الحديث.
- تُعرض الخلافات العلمية بدل دمجها في درجة واحدة مصطنعة.
- لا تُخترع أرقام صفحات أو طبعات أو بيانات ببليوغرافية.
- الذكاء الاصطناعي مساعد في الاستخراج والمطابقة والاسترجاع والتلخيص، وليس بديلًا عن المراجعة العلمية.

## سير البيانات
Draft → Review → Verified → Published

## البنية المستهدفة
- GitHub: الكود والإصدارات.
- PostgreSQL/Supabase: قاعدة البيانات.
- Cloud Storage: ملفات المصادر الأصلية.
- RAG: إجابات مؤسَّسة على مصادر موثقة مع إظهار الإحالات.

## تشغيل النسخة التجريبية
يمكن فتح `index.html` مباشرة في المتصفح.

## GitHub Pages
بعد رفع الملفات إلى المستودع:
Settings → Pages → Deploy from a branch → main → / (root)

> هذه النسخة ما تزال نموذجًا أوليًا؛ التخزين الحالي في المتصفح وليس قاعدة بيانات إنتاجية.
