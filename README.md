# 📚 بصيرة الحديث — Basira Hadith

منصة أكاديمية متخصصة في تنظيم المصادر الحديثية والسجلات الحديثية والمراجعة العلمية، مع تصميم قابل للتوسع نحو البحث الموجّه بالمصادر (RAG) والذكاء الاصطناعي.

## الإصدار الحالي
**v1.0 — Research Workflow Prototype**

### ما الذي أصبح يعمل؟
- لوحة متابعة حقيقية مبنية على البيانات المحلية.
- إدارة المصادر والبيانات الببليوغرافية.
- ربط الحديث بالمصدر.
- إدخال النص الأصلي والسند والمتن في حقول مستقلة.
- البحث في المصادر والأحاديث.
- حالات: مراجعة → موثق → منشور.
- لوحة للمراجعة العلمية.
- فهرس موحد.
- تصدير نسخة احتياطية JSON.
- وضع ليلي.
- تصميم متجاوب للهاتف والكمبيوتر.
- عدم إصدار حكم حديثي آلي.

## الضابط العلمي
المنصة لا تعتبر التشابه النصي أو نتيجة الخوارزمية حكمًا حديثيًا. أي حكم أو نسبة إلى عالم يجب أن يكون له مصدر وموضع، وتُحفظ الأحكام المختلفة مستقلة عن بعضها.

## التخزين الحالي
هذه النسخة تستخدم **LocalStorage** في المتصفح. لذلك لا توجد مشاركة للبيانات بين الأجهزة أو المستخدمين.

قبل إدخال بيانات بحثية مهمة استخدم زر **تصدير نسخة احتياطية**.

## البنية المستهدفة
1. GitHub Pages — الواجهة والنشر.
2. PostgreSQL / Supabase — قاعدة البيانات.
3. Object Storage — ملفات الكتب والمصادر.
4. API — طبقة الخدمات.
5. RAG — استرجاع قائم على المصادر مع إحالات واضحة.
6. AI — استخراج ومطابقة وتلخيص مساعد، مع مراجعة بشرية إلزامية.
