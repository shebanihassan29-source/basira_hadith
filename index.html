📖 المنهجية العلمية

الضوابط التي تحكم بناء «بصيرة الحديث».

1. أولوية المصدر

كل سجل حديثي يجب أن يرتبط بمصدر محدد وموضع يمكن الرجوع إليه. لا تُخترع الصفحات أو الطبعات أو البيانات الببليوغرافية.

2. حفظ النص الأصلي

يبقى النص الأصلي كما أدخله الباحث، وتكون أي عمليات تنظيف أو تحليل في حقول منفصلة قابلة للمراجعة.

3. استقلال الأحكام

عند إضافة أحكام المحدثين تُحفظ كل نسبة إلى صاحبها ومصدرها، ولا تُدمج في «درجة» واحدة دون منهج معلن.

4. الذكاء الاصطناعي مساعد

يمكن استخدامه للاستخراج والمطابقة والتلخيص والاسترجاع الموجّه بالمصادر، مع إظهار الإحالات واشتراط المراجعة البشرية.

5. سجل التدقيق

الهدف في الإصدارات اللاحقة هو تسجيل من عدّل السجل ومتى ولماذا، مع حفظ النسخ السابقة للبيانات.

6. قابلية التوسع

هذه النسخة تعمل محليًا في المتصفح. البنية المستهدفة لاحقًا: PostgreSQL/Supabase + تخزين ملفات + API + RAG موثّق.

ملاحظة: النسخة الحالية لا تحتوي على قاعدة بيانات خادمية. البيانات التي تُدخل هنا تُحفظ في LocalStorage لهذا المتصفح، ويمكن تصديرها كنسخة JSON احتياطية.
